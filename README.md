# 澤井珈琲「世界をひとめぐりする、秋の珈琲旅。」霜降キャンペーンLP

10月5日〜10月23日「霜降」限定、10月のおすすめレギュラーコーヒー3種60杯分福袋(ジャーマンクラシック・金のビターブレンド・秋のブレンド イタリアナポリ風)の1,000円OFFクーポン・ポイント10倍キャンペーンページです。雑誌風の編集ページとして、3種類のブレンドを「3つの寄港地をめぐる旅」として見せる構成にしています。

## ファイル構成

```
index.html          … 特集ページ本体(HTML+CSS+JS、すべてこの1ファイルに含まれています)
images/
  header/            … ヘッダーのロゴ画像
  product/            … 商品写真(楽天商品ページ掲載の公式画像を加工して使用)
```

## 設定済みの内容

- **クーポン取得URL**は未設定です(`#` のまま)。発行後に差し替えが必要です。
- **商品ページURL**は設定済みです(`https://item.rakuten.co.jp/sawaicoffee-tea/ac-september/`)。
- **カウントダウン**は「2026年10月5日 0:00 開始 〜 10月23日(霜降) 23:59 終了」に設定済みです。開始前は「開始まで」、開催中は「霜降(10月23日)まで」と表示が切り替わり、終了後はクーポンボタンが自動的に無効化されます。

## ご対応・ご確認いただきたい項目

### 1. クーポン取得URLの設定(必須)

`index.html` 内の `<script>` タグ内、`COUPON_URL` を実際のクーポン取得URLに書き換えてください。

### 2. 期間・価格・クーポンの最終確認

| 項目 | 現在の設定 |
|---|---|
| 開催期間 | 2026年10月5日 0:00 〜 10月23日(霜降) 23:59 |
| 通常価格 | 3,605円 |
| クーポン | 1,000円OFF・ポイント10倍 |
| クーポン適用後価格 | 2,605円 |
| 内容量 | 200g×3袋(60杯分) |

### 3. フレーバーメーター(香り・コク・酸味・苦味)について

ROUTE 01〜03の各ブロックにあるバーは、商品ページ掲載の焙煎豆アイコン表示を参考に作成した独自の簡易メーターです(厳密な測定値ではありません)。変更する場合は `index.html` 内、各 `.sw-meter-fill` の `style="width:◯%"` を編集してください。

### 4. レビューの数値について

「総合評価4.75(16件)」および引用2件は、掲載時点の楽天レビューを元にしたテキストです。最新の数値・声に更新する場合は `index.html` 内の `REVIEW` セクションを直接編集してください。

## 実装上のご注意

- JavaScriptを使用しています(カウントダウン、クーポンURLの一括設定)。
- レスポンシブ対応済みで、スマホ表示を基準に作成し、768px以上でPC向けレイアウトに切り替わります。
- フォントは Google Fonts(Jost / Noto Sans JP / Zen Old Mincho)を外部読み込みしています。本文・数字・各見出しは「家具のソムリエ」お弁当箱比較ページと同じ Noto Sans JP + Jost の組み合わせに揃え、ファーストビューのメイン見出し(「世界をひとめぐりする、秋の珈琲旅。」)のみ雑誌らしい明朝体(Zen Old Mincho)を使用しています。
- ファーストビューは写真に見出し・リード文・クーポンバッジを重ねる構成です。暗めのグラデーション(スクリム)を写真全体にかけることで、文字をtext-shadowに頼らず読みやすくしています。クーポン適用後価格(3,605円→2,605円)もこのバッジ内に明示しています。
- 写真はCSSアニメーションでゆっくりズーム(Ken Burns効果)するのみのシンプルな演出です。動画ファイルは使用していません。
- 「いれたての一杯が、ちょうど注がれるところ。」というテキスト付きの小さなアニメーションカードは削除し、代わりに各ブロック見出しの横に小さな湯気アイコンを再利用しています。
- ファーストビューの写真(`hero-coffee-light.jpg`)はユーザー提供の素材です。各ROUTE・最終ブロックの商品写真は、楽天商品ページ(`ac-september`)に掲載されている公式画像を、見出し・説明文などの文字要素を除いてトリミング加工したものです。
